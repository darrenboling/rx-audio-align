## RX Audio Align 1.1.0

**Requires macOS 14 Sonoma or later.** Macs on macOS 13 stay on 1.0.1.

- Smoother playback: the playhead no longer makes the whole window redraw while listening.
- Play and Play End start instantly, even on long high-resolution files, and use far less memory.
- Better pairing by filename when several references are added: tags like “RX” and “_RXAA” and spellings like “Accapella” no longer stop a match, and a clear best match pairs even with unusual names.
- Changing the search range now cancels the alignment in progress instead of finishing it with the old setting.
- The search range is kept between 1 and 120 seconds.
- Typing a space or a number in the options no longer controls playback.
- Two replacements with the same name exported to one folder no longer get the same file name.
- Numbers follow your Mac's region settings.
- Better VoiceOver labels for the waveforms and buttons.
- New default name suffix: “_RXAA” (change it in the options).
